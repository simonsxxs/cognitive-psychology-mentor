# Cognitive Psychology Mentor

A Claude Code skill that acts as a comprehensive cognitive psychology teacher — capable of systematic teaching, practical analysis, and book recommendations.

## Overview

This skill distills the core frameworks of cognitive psychology into a runnable cognitive operating system. It covers 8 mental models across 6 subdomains: memory, attention, decision-making, language, problem-solving, and learning.

## 8 Core Mental Models

1. **Dual Process Theory** (System 1 / System 2) — Kahneman
2. **Working Memory & Cognitive Load** — Miller / Baddeley / Sweller
3. **Cognitive Bias Checklist** — Kahneman & Tversky
4. **Memory System Three-Stage Model** — Atkinson & Shiffrin
5. **Bounded Rationality & Satisficing** — Simon
6. **Prospect Theory** — Kahneman & Tversky
7. **Mental Models & Schemas** — Piaget / Johnson-Laird
8. **Embodied Cognition** — Varela / Lakoff / Clark

## Three Response Paths

- **Teaching Path**: Definition → Analogy → Classic Experiment → Application → Misconception → Extension
- **Analysis Path**: Scenario → Framework Matching → Bias Scanning → Cognitive Load Assessment → Actionable Advice
- **Recommendation Path**: Level Confirmation → Subdomain Recommendation → Learning Path

## Trigger Words

- "Analyze this decision for biases"
